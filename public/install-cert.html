Install the CMS certificate

One-time setup for this device. After this, it'll connect to this CMS with no security warnings — for this competition and any future one run from the same installation.

Download certificate

Android:
  1. Tap "Download certificate" above (or scan the QR with your camera).
  2. Open the downloaded file from the notification, or from the Files app's Downloads folder.
  3. If nothing happens: open Settings, tap the search icon, type "certificate", and choose Install a certificate → CA certificate.
  4. Confirm the warning — this is expected for a locally-issued certificate.
iPhone / iPad:
  1. Tap "Download certificate" above (or scan the QR with your camera).
  2. Safari will offer to open a profile — go to Settings, tap "Profile Downloaded" at the top, then Install.
  3. This step is easy to miss: go to Settings → General → About → Certificate Trust Settings and turn on full trust for "Atlas Local CA." Without this, iOS won't trust it for websites yet.
Desktop Chrome:
  1. Open chrome://settings/certificates → Authorities tab → Import.
  2. Select the downloaded ca.crt file.
  3. Check "Trust this certificate for identifying websites."
Desktop Firefox:
  1. Settings → Privacy & Security → Certificates → View Certificates → Authorities tab → Import.
  2. Select the downloaded ca.crt file and check "Trust this CA to identify websites."

Once installed, ask the operator for a pairing code — or scan their QR — to finish setting up the e-scoresheet.
