👤 People Manage fencers, referees and club members. Import from CSV. 🏆 Events Create tournaments and competitions. Set up age categories and weapon. ⚔️ Strips / Pistes Add and manage pistes. Assign to pools during competition.
Typical workflow
1. Add fencers to the master list (or import a CSV).
2. Create a competition — set weapon, gender, age categories.
3. Open the competition → select eligible fencers → auto-seed.
4. Create a pool phase → choose a rule → pools and bout order are generated automatically.
5. Open a pool scoresheet (tablet) → enter scores.
6. Close the phase → rankings computed → eliminated fencers marked.
