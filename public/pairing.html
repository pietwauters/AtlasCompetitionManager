Device-locked credentials Preferred

▾

The device generates its own key and never exposes it — enter a code on the device itself to pair. Used by scoring apparatus and other hardware that runs its own dedicated software.

DeviceRoleIssuedStatus

Revoking regenerates the certificate revocation list (CRL) in Atlas's own database, but the broker only enforces it once an admin runs scripts/sync-mosquitto-tier-a.sh to push the updated CRL. "Clear revoked from this list" only tidies this page — it never un-revokes anything at the broker.

Username & password Fallback

▾

Fallback for browser-based apps, which can't use device-locked credentials at all — no webpage can present a security certificate.

DeviceAssignedStatus

Revoking here stops future pairing and marks the device revoked, but the credential stays valid at the broker until an admin runs scripts/sync-mosquitto-scoresheet-acl.sh to push the change. "Clear revoked from this list" only tidies this page — it never re-authorizes anything at the broker.
